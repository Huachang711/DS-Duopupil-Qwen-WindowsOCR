# 🔑 百炼 API Key 获取教程（图文级步骤）

> 适用：阿里云百炼（Model Studio / Bailian）。全程约 3 分钟。
> 官方文档：[获取 API Key](https://www.alibabacloud.com/help/zh/model-studio/get-api-key)

## 第 1 步：打开百炼控制台

浏览器访问：**https://bailian.console.aliyun.com**

- 没有阿里云账号 → 先注册并完成实名认证（免费，几分钟）；
- 已有账号 → 直接登录。

## 第 2 步：进入 API-KEY 管理页

有两种入口，任选其一：

- **入口 A（推荐）**：控制台右上角**头像** → 下拉菜单点 **「API-KEY」**；
- **入口 B**：直接访问 `https://bailian.console.aliyun.com/?apiKey=1#/api-key`。

> 旧版控制台可能在左侧菜单栏"模型服务"下方，找不到就用入口 B 的直达链接。

## 第 3 步：确认业务空间

页面上方通常有"业务空间"下拉框：

- 默认空间即可（个人使用）；
- 有多个空间时，选你要用的那个（API-KEY 归属当前空间）。

## 第 4 步：创建 API-KEY

1. 点 **「创建我的 API-KEY」** 按钮；
2. 弹出窗口里给 Key 起个名字（如 `duopupil`，可随意）；
3. 点 **「创建」**；
4. 页面会显示以 **`sk-` 开头**的一长串字符——这就是你的 API-KEY。

## 第 5 步：复制并保存（重要）

1. 点 **复制**；
2. 打开双瞳方案文件夹里的 `模型.txt`（填写卡）；
3. **删掉卡内全部文字**，把 Key **单行**粘贴进去，保存（UTF-8）；
4. 保存后文件应**只有一行、以 `sk-` 开头**。

> ⚠️ Key 只在创建时完整显示一次，之后控制台只显示前后几位。**当场复制**，别关页面后再找。

## 第 6 步：确认模型与额度

1. 控制台 → **模型广场**：确认你要用的视觉模型已开通（如 `qwen3.5-omni-plus`、`qwen3.5-omni-flash`、`qwen-vl-plus` 等）。大多数模型**即开即用**；个别需点「开通」（免费）；
2. **计费**：百炼为按量付费，新用户通常有免费额度；正式使用前建议在"费用/账单"页面确认余额或充值。

## 安全建议

- 🔒 用**可随时吊销的子 Key**（创建时如有相关选项，或创建多个 Key 分用途）；
- 🔄 Key 泄露 → 立即在 API-KEY 列表 **删除/停用** 并重建，然后更新 `模型.txt`；
- 🚫 不要把 Key 发进聊天、写进文档、上传到 GitHub。

## 常见问题

| 问题 | 处理 |
|------|------|
| 找不到「API-KEY」入口 | 用直达链接 `https://bailian.console.aliyun.com/?apiKey=1#/api-key`，或检查是否登录错账号 |
| 创建按钮灰色 | 先完成实名认证 / 勾选同意服务协议 |
| 调用报 `ModelNotOpen` | 该模型未开通 → 控制台模型广场点「开通」 |
| 调用报 429/欠费 | 额度用完或未开通按量付费 → 控制台"费用"页充值/开通 |
| 忘记 Key 完整值 | 控制台只能看首尾几位 → 删除旧 Key 重新创建一个 |
