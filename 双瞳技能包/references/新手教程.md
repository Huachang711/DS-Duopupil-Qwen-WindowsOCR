# 双瞳 DuoPupil · 新手教程

> 本教程面向 Windows 10/11 用户，从零到"截图 → 聊天提问"全程图文级步骤。预计耗时 10 分钟。

## 第 0 步：双瞳是什么（30 秒）

- **双瞳** = 两只眼睛：Windows 自带 OCR（识字，免费本地）+ 阿里云百炼视觉模型（识图，付费按 token）；
- 配套的**截图工具**：微信式截图 + 全局热键 + **DP 图片代码**；
- 典型用法：按热键截图 → 聊天里 Ctrl+V 粘贴代码 → AI 自动读图回答。

## 第 1 步：拷贝文件夹

把整个 `双瞳识图方案` 文件夹拷到你的电脑任意位置（桌面、D 盘都行）。核心三件：`双瞳识图方案手册.md`、`模型.txt`、`工具` 文件夹。

## 第 2 步：准备百炼 API Key

**完整图文步骤见 [🔑 百炼API获取教程.md](百炼API获取教程.md)**。简要版：

1. 打开百炼控制台 https://bailian.console.aliyun.com ，登录阿里云账号；
2. 右上角头像 → 「API-KEY」→ 创建 → 复制 `sk-` 开头的 Key；
3. 建议用可随时吊销的子 Key。

## 第 3 步：填写 Key

1. 在文件夹里找到 **`模型.txt.example`**（模板）→ **复制一份并重命名为 `模型.txt`**；
2. 打开 `模型.txt`，**删掉全部文字**，把 Key **单行**粘贴进去，保存（UTF-8）；
3. 保存后文件应该只有一行、以 `sk-` 开头。

> 安全约定：`模型.txt` 已被 `.gitignore` 排除，不会被上传；Key 永远不要发进聊天、写进文档或分享给别人。

## 第 4 步：编译启动器 + 建桌面快捷方式（一次性的）

1. 按 `Win+R` 输入 `powershell` 回车；
2. 执行（路径换成你的实际路径）：

```
csc /nologo /target:winexe /out:"<你的路径>\工具\DuoPupil.exe" "<你的路径>\工具\launcher.cs"
```

> 找不到 csc 时用完整路径：`%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`

3. 在 `工具` 文件夹里**右键 `DuoPupil.exe` → 发送到 → 桌面快捷方式**，重命名为"双瞳"；
4. （可选）把本机脚本策略设为 RemoteSigned（在 PowerShell 里执行）：

```
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

## 第 5 步：第一次打开（环境自检）

双击桌面「**双瞳**」→ 深色面板弹出：

```
区域截图 / 全屏截图 / 驻留托盘 / 打开图片文件夹 / 快捷键说明 / 快捷键设置
右上角：图钉(置顶) ─ ×
```

如果你想用 AI 引导（推荐）：新开一个聊天，说：

```
请阅读 <你的路径>\双瞳识图方案手册.md，并按「首次使用：环境自检」执行。
```

AI 会依次检查 Key、OCR 引擎、中文语言包、网络权限，并自动拉取你账号的模型列表、推荐 A/B/C 三档——你只需要确认。

## 第 6 步：截图与热键

| 方式 | 操作 |
|------|------|
| 面板按钮 | 点「区域截图」拖框；或「全屏截图」 |
| 热键 | `Ctrl+Alt+S`（默认，仅面板开着或托盘驻留时有效） |
| 托盘 | 点「驻留托盘」后，面板关了热键也有效；彻底关闭 = 右键托盘图标 → 退出 |

截图操作：拖框（绿框+压暗）→ 松手可按住框内移动 → 选框右下角【确认】【文字提取】【退出】；单击/回车=全屏，Esc=退出。确认后右下角提示"已保存，图片代码已复制到剪贴板"。

改热键：面板「快捷键设置」→ 点绿色按钮后**直接按下**想要的组合键（如 `Ctrl+Shift+D`）即可，无需手动输入。

## 第 7 步：用 DP 代码和 AI 聊天（核心玩法）

1. 截图并确认后，代码已在剪贴板（形如 `DP-20260816-083600`）；
2. 回到聊天窗口，直接 **Ctrl+V** 粘贴，然后提问，例如：

```
DP-20260816-083600 这张图里有什么内容？
```

3. AI 收到代码会自动读取对应截图（含已识别的文字），回答你，并询问是否需要付费的视觉模型进一步分析。

> 连截多张？默认是"单条模式"（粘贴永远一行）。想要一次贴多个代码：面板 → 快捷键设置 → 图片代码设置 → 切换多代码模式。

## 第 8 步：深入识图（可选付费）

当需要"看懂"图（色彩/风格/语义）时，AI 会给你三个档位选：

- **A 日常档**（推荐默认）：快、省，日常够用；
- **B 旗舰档**：最强精度；
- **C 兜底档**：A/B 不可用时降级。

你确认后 AI 才调用，并在每次调用后报告 token 消耗。图片此时会上传至阿里云，敏感图请自行权衡。

## 常见问题排查

| 现象 | 处理 |
|------|------|
| 双击没反应/找不到窗口 | 双击「双瞳」= 覆盖式启动（自动关旧开新）；再双击一次即可 |
| 杀软拦截快捷方式 | 见手册「杀软误报说明」：用 exe 入口 + 方案目录加信任区 |
| 热键没反应 | 面板/托盘都没开；或组合键被占用（启动会弹警告）→ 换组合 |
| 热键有延迟/时灵时不灵 | 双击「双瞳」重启（保证加载最新代码） |
| 托盘图标找不到 | 点任务栏 `^` 展开；退出 = 右键图标 → 退出 |
| 提示"热键注册失败" | 该组合被其他软件占用，换一个 |

## 卸载

删除桌面快捷方式 + 删除整个 `双瞳识图方案` 文件夹即可，系统无任何残留（无自启、无注册表项、无后台服务）。
