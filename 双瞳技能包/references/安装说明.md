# 双瞳截图工具 · 安装说明（AI 执行手册）

> 本说明面向代理/AI：在用户机器上把 references 里的工具落地到方案包，并处理快捷方式与杀软问题。

## 1. 工具落位

- 把本目录（references）中以下文件复制到方案包根目录下的 `工具\` 文件夹：
  `双瞳截图.ps1`、`双瞳托盘.ps1`、`ui.txt`、`双瞳.ico`、`launcher.cs`
- `双瞳截图.ps1` 会按自身位置定位包内 `图片` 文件夹并自动创建，无需额外配置。

## 2. 编译干净启动器（规避火绒 LNKAgent 误报）

在本机执行（无需联网）：

```
csc /nologo /target:winexe /out:"<本目录>\工具\DuoPupil.exe" "<本目录>\工具\launcher.cs"
```

csc 路径（二选一）：`%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 或 `Framework\...`。

## 3. 创建桌面快捷方式（询问用户后执行）

- 名称：`双瞳`
- 目标：`<本目录>\工具\DuoPupil.exe`
- 参数：`<本目录>\工具\双瞳截图.ps1`（脚本路径经参数传入，启动器会隐藏控制台无闪现）
- 图标：`<本目录>\工具\双瞳.ico,0`

**覆盖式启动**：双击即自动关闭旧实例（面板或托盘）再开新面板，无需用户找旧窗口。

## 4. 执行策略（一次性）

```
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

之后所有启动命令无需 `-ExecutionPolicy Bypass`。

## 5. 杀软信任区（提示用户操作）

火绒：主界面 → 右上角菜单 → 信任区 → 添加文件夹 `<方案根目录>`。
原因：工具的"快捷方式→powershell→隐藏窗口→脚本"模式会被启发式误报为 `HEUR:Trojan/LNKAgent.b`；exe 启动器 + 信任区双保险。

## 6. 热键与托盘（告知用户）

- 默认 `Ctrl+Alt+S`（存于 `工具\hotkey.cfg`，可按键捕捉自定义，须含 Ctrl 或 Alt）；
- 生效条件二选一：面板开着，或点面板「驻留托盘」；
- 彻底关闭：右键托盘图标 → 退出；
- 无自启、无残留。

## 7. DP 图片代码协议

- 每次保存截图生成代码 `DP-日期-时间`，写入 `工具\pending.txt` 并复制到剪贴板；模式可配（默认单条模式，可在「快捷键设置」→「图片代码设置」切换多代码模式）；
- 代码 ↔ 文件换算：`DP-20260816-081530` ↔ `ScreenShot_2026-08-16_081530.png/.txt`；
- AI 收到代码后读同名 txt 汇报 OCR，并按手册「第 0 步」路由继续；处理完清空 pending.txt。
