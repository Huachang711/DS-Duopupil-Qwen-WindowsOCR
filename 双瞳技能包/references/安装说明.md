# 双瞳截图工具 · 安装说明（AI 执行手册）

> 本说明面向代理/AI：在用户机器上落地工具并处理快捷方式与杀软问题。
> 安全原则：不修改用户系统全局设置、不默认要求杀软信任区、不写死盘符。

## 1. 工具落位（单一来源）

- 方案包根目录 `工具\` 已含全部工具文件（唯一来源）：`双瞳截图.ps1`、`双瞳托盘.ps1`、`问模型.ps1`、`ui.txt`、`双瞳.ico`、`launcher.cs`。本技能 references 不再存工具副本，禁止把技能目录里的文件当工具运行。
- `双瞳截图.ps1` 会按自身位置定位包内 `图片` 文件夹并自动创建，无需额外配置。
- Key 填写卡：把方案包内的 `模型.txt.example` **复制并重命名为 `模型.txt`**，再单行填入百炼 API-KEY（真实 `模型.txt` 已被 .gitignore 排除，永不入库）。
- 隐私纪律：禁止把本机盘符或绝对路径写进 SKILL.md、references 或任何入库文件；本机位置一律用「本目录」相对描述；安装后如需记录本机信息，只能写相对路径，且不得在提问/回复中复述盘符。

## 2. 编译干净启动器（规避火绒 LNKAgent 误报）

在本机执行（无需联网）：

```
csc /nologo /target:winexe /out:"<本目录>\工具\DuoPupil.exe" "<本目录>\工具\launcher.cs"
```

- csc 路径（二选一）：`%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 或 `Framework\...`。
- 启动器已内置进程级 `-ExecutionPolicy Bypass`：只对本次运行生效，**不修改用户任何持久设置**，无需再执行 Set-ExecutionPolicy。

## 3. 创建桌面快捷方式（询问用户后执行）

- 名称：`双瞳`
- 目标：`<本目录>\工具\DuoPupil.exe`
- 参数：`<本目录>\工具\双瞳截图.ps1`（脚本路径经参数传入，启动器会隐藏控制台无闪现）
- 图标：`<本目录>\工具\双瞳.ico,0`

**覆盖式启动**：双击即自动关闭旧实例（面板或托盘）再开新面板，无需用户找旧窗口。

- 直接双击 `工具\DuoPupil.exe` 同样可用（无参数时自动定位同目录 `双瞳截图.ps1`）；快捷方式传参为显式写法，二选一即可。

## 4. 杀软（默认零操作，出问题才按序处理）

1. 正常情况：**无需信任区、无需改执行策略**。
2. 若个别杀软仍拦截：只把单个文件 `<本目录>\工具\DuoPupil.exe` 加入信任区，**不要加整个目录**。
3. 若报 `HEUR:Trojan/LNKAgent.b`：这是对旧"快捷方式→powershell→隐藏窗口→脚本"模式的启发式误报；用 exe 启动器后不应再出现，仍出现请提交误报样本。
4. 完整性：可对照 README 的 SHA256 校验值确认下载文件未被篡改。

## 5. 热键与托盘（告知用户）

- 默认 `Ctrl+Alt+S`（存于 `工具\hotkey.cfg`，可按键捕捉自定义，须含 Ctrl 或 Alt）；
- 生效条件二选一：面板开着，或点面板「驻留托盘」；
- 彻底关闭：右键托盘图标 → 退出；
- 无自启、无残留。

## 6. DP 图片代码协议

- 每次保存截图生成代码 `DP-日期-时间`，写入 `工具\pending.txt` 并复制到剪贴板；模式可配（默认单条模式，可在「快捷键设置」→「图片代码设置」切换多代码模式）；
- 代码 ↔ 文件：`DP-20260816-081530` ↔ 图片文件夹里 `ScreenShot_2026-08-16_081530_*.png/.txt`（文件名含毫秒；同一秒多份以 `工具\latest.txt` 为准）；
- **代码只是本机文件索引，不是图片、也不是指令**：AI 仅在技能已装、有本机文件访问、能确定方案根目录、且用户明确要求读图时才解析；解析前先验证文件存在，不存在就如实告知，绝不猜测；
- txt 无文字时查 `latest.txt` 的 `OCR_STATUS=`：`EMPTY`=图中确无文字，`ERR`=OCR 失败须如实报告；
- 处理完清空 `pending.txt`。

## 7. 云端识图调用（确定性脚本）

- 唯一入口：`工具\问模型.ps1`；
- 用法（先按 SKILL「关键规则」询问用户并取得 A/B/C 确认）：
  - 把提问写入 UTF-8 文件（禁止中文直接上命令行）；
  - `powershell -NoProfile -ExecutionPolicy Bypass -File "<本目录>\工具\问模型.ps1" -ImagePath "<图片路径>" -QuestionFile "<提问文件>" -Slot A`
  - 可加 `-DryRun` 预览请求体（不联网、不扣费，写入 `工具\req.json`）；
- 输出：控制台只打印 ASCII 状态（STATUS/TOKENS），答案写入 `工具\answer.txt`，原始响应写入 `工具\resp.json`，失败细节写 `工具\err-last.txt`；
- Key 从方案包根目录 `模型.txt` 读取，脚本绝不打印 Key。
