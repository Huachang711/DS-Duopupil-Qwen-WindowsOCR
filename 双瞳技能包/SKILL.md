# 双瞳识图方案（DuoPupil）

让没有视觉能力的文本大模型"看图"：截图工具负责采集（本地免费 OCR 随存随做），百炼 VL 负责看懂（付费按 token）。本技能为规则主干；完整细节见 `references/手册全文.md`。

## 触发场景

- 用户说"截图 / 运行截图工具 / 启动托盘" → 按 `references/安装说明.md` 启动工具；
- 用户粘贴 `DP-` 开头的图片代码并提问 → 按下方协议解析作答；
- 用户要求识别任意本地图片 → 按本技能流程执行（OCR 探路 → A/B/C 询问 → 调用 → token 报告）。

## 图片代码协议（DP）

**铁律：任何会话收到 `DP-` 开头的代码，即代表用户要求"读取对应截图并回答"——立即按本协议解析并作答，无需用户再解释意图。**

- 截图工具每次保存生成代码 `DP-日期-时间`，写入 `工具\pending.txt` 并复制到剪贴板；模式可配（默认单条模式，可在「快捷键设置」→「图片代码设置」切换多代码模式）；截图文件按"保留最近 50 张"自动轮换；
- 代码与文件按约定换算：`DP-20260816-081530` 对应图片文件夹里的 `ScreenShot_2026-08-16_081530.png` 与同名 `.txt`（OCR 已随保存完成）；
- 收到代码后：读同名 `.txt` → 有文字：汇报 OCR 结果并询问是否需要 VL 分析；无文字：直接进入 A/B/C 询问；
- 多个代码 = 多图：先问用户"逐张询问 / 批量沿用同一档 / 分批处理"；
- 处理完成后清空 `工具\pending.txt`。

## 关键规则

1. 调用任何 VL 模型前必须先询问用户并展示 A/B/C 三档（日常/旗舰/兜底，实际模型码以 `槽位配置.txt` 为准），用户确认后才调用；
2. 调用失败：立即停止、报告错误码与原因、询问是否换档——绝不自动降级、绝不猜测图片内容；
3. 每次调用后报告 token 消耗（本次明细 + 会话累计）；
4. 图片会上传至阿里云百炼服务器：调用前提醒用户，敏感图片由用户自行权衡；
5. 需要提权审批前先向用户预告（次数/原因/顺序），确认后再执行；
6. Key 只存 `模型.txt`（首次使用：把仓库里的 `模型.txt.example` 复制为 `模型.txt` 再填写），永不写进文档或聊天；模型槽位只写 `槽位配置.txt`，不改手册模板；
7. UTF-8 纪律：中文提示词先写入文件再读取，响应原始字节落盘后用文件工具读取，禁止控制台打印中文；
8. 隐私纪律：SKILL.md 与 references 中禁止写死盘符或绝对路径，本机位置一律用「本目录」相对描述；回复与提问中除非用户明确要求，否则不得复述盘符、绝对路径、用户名或 Key。

## 工具文件

- `references/双瞳截图.ps1`：主工具（面板 + 全局热键 + 微信式截图 + DP 代码 + 快捷键设置）
- `references/双瞳托盘.ps1`：可选驻留托盘（热键常驻，右键退出彻底关闭）
- `references/launcher.cs`：干净启动器源码（安装时用本机 csc 编译为 exe，规避杀软 LNKAgent 误报）
- `references/ui.txt`、`references/双瞳.ico`：界面文字与图标
- 安装步骤、快捷键机制、杀软信任区指引：见 `references/安装说明.md`

## 环境要求

- Windows 10/11 + PowerShell；截图与 OCR 全程本地免费零联网；
- VL 识别需要百炼 API Key（`模型.txt`）与额度；DashScope 为国内服务，海外网络可能较慢。
