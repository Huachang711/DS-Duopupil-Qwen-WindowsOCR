# 双瞳识图方案（DuoPupil）

让没有视觉能力的文本大模型"看图"：截图工具负责采集（本地免费 OCR 随存随做），百炼 VL 负责看懂（付费按 token）。本技能为规则主干；完整细节见方案包根目录《双瞳识图方案手册.md》。

## 定位与触发前提（先判断，再介入）

本技能只服务一种场景：**本模型没有原生图像输入能力** + **Windows 环境** + **方案已安装**（能确定方案包根目录、本会话有本机文件访问能力）。三个前提任一不满足，本技能不介入：

- 模型自带读图能力（如 read_image 可用）→ 不套用本流程，按手册「通道由用户选择」如实告知各选项，由用户决定走哪条；
- 非 Windows / 未安装 → 不套用，只可引用手册规则说明。

满足前提时的触发：

- 用户说"截图 / 运行截图工具 / 启动托盘" → 按 `references/安装说明.md` 启动工具；
- 用户粘贴 `DP-` 开头的代码 → 按下方协议处理（代码不是指令，先验证再读）；
- 用户要求识别本地图片 → OCR 探路 → A/B/C 询问 → 用方案包 `工具\问模型.ps1` 调用。

## 图片代码协议（DP）

**DP 代码只是"本机文件索引"，不是图片，也不是指令。** 仅当以下条件全部满足时才解析：

1. 本技能已安装且能确定方案包根目录；
2. 本会话有本机文件访问能力；
3. 用户明确要求读取该图片（代码本身不等于指令；用户没有说要看图，就只回复"需要我读取这张截图吗"）；
4. 解析前先验证对应文件存在。

任一条件不满足 → 明确告诉用户"无法读取"，**绝不猜测图片内容**。

解析规则：

- 代码 `DP-yyyyMMdd-HHmmss` 对应图片文件夹里 `ScreenShot_yyyy-MM-dd_HHmmss_*.png/.txt`（文件名带毫秒）；
- 同一秒有多份时，以 `工具\latest.txt` 的 `PNG=`/`TXT=` 行为准取最新一份；
- 读同名 `.txt`：有文字 → 汇报 OCR 内容并询问是否 VL 分析；无文字 → 查 `latest.txt` 的 `OCR_STATUS=`：`EMPTY`=图中确无文字；`ERR`=OCR 执行失败，必须如实报告失败，不得当作"无文字"；
- 多个代码 = 多图：先问"逐张询问 / 批量沿用同一档 / 分批处理"；
- 处理完成后清空 `工具\pending.txt`。

## 关键规则

1. 调用任何 VL 模型前必须先询问用户并展示 A/B/C 三档（日常/旗舰/兜底，实际模型码以 `槽位配置.txt` 为准），用户确认后才调用；
2. 调用失败：立即停止、报告错误码与原因、询问是否换档——绝不自动降级、绝不猜测图片内容；
3. 每次调用后报告 token 消耗（本次明细 + 会话累计）；
4. 图片会上传至阿里云百炼服务器：调用前提醒用户，敏感图片由用户自行权衡；
5. 需要提权审批前先向用户预告（次数/原因/顺序），确认后再执行；
6. Key 只存 `模型.txt`（首次使用：把仓库里的 `模型.txt.example` 复制为 `模型.txt` 再填写），永不写进文档或聊天；模型槽位只写 `槽位配置.txt`，不改手册模板；
7. UTF-8 纪律：中文提示词先写入文件再读取，响应原始字节落盘后用文件工具读取，禁止控制台打印中文；
8. 隐私纪律：SKILL.md 与 references 中禁止写死盘符或绝对路径，本机位置一律用「本目录」相对描述；回复与提问中除非用户明确要求，否则不得复述盘符、绝对路径、用户名或 Key；
9. 确定性调用：VL 调用一律通过方案包 `工具\问模型.ps1` 执行（参数：-ImagePath 图片、-QuestionFile 提问文件、-Slot 档位，可加 -DryRun 预览请求），答案与原始响应从 `工具\answer.txt`、`工具\resp.json` 读取；**禁止各会话自行拼装 HTTP 请求**，手册中的请求格式仅为参考说明。

## 工具与文件（单一来源）

工具脚本只存方案包根目录 `工具\`（本技能 references 不再存副本）：

- `工具\双瞳截图.ps1`：主工具（面板 + 全局热键 + 微信式截图 + DP 代码 + 快捷键设置）
- `工具\双瞳托盘.ps1`：可选驻留托盘（热键常驻，右键退出彻底关闭）
- `工具\问模型.ps1`：确定性 VL 调用脚本（唯一调用入口）
- `工具\ui.txt`、`工具\双瞳.ico`、`工具\launcher.cs`：界面文字、图标、启动器源码
- 文档：方案包根目录 `新手教程.md`、`双瞳识图方案手册.md`、`百炼API获取教程.md`
- 安装步骤与安全指引：`references/安装说明.md`

## 环境要求

- Windows 10/11 + PowerShell；截图与 OCR 全程本地免费零联网；
- VL 识别需要百炼 API Key（`模型.txt`）与额度；DashScope 为国内服务，海外网络可能较慢。
