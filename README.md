## 🤔 为什么要做双瞳？

很多强大的文本大模型**没有视觉能力**：发不了图、读不了图、聊天界面不支持上传。于是有了一个朴素的念头——

> **既然模型看不见，就给它装眼睛：一只本地免费的"识字眼"，一只云端专业的"识图眼"。**

双瞳因此诞生：

- 🆓 **左瞳（本地 OCR）**：Windows 自带引擎，免费、本地、零联网——先"认字"探路；
- 💰 **右瞳（百炼 VL）**：阿里云百炼 Qwen 视觉模型——真正"看懂"色彩、风格、语义；
- 👑 **用户掌舵**：用哪只眼、用哪档模型、花不花钱，**全部由用户拍板**，AI 绝不擅作主张。

## ✨ 功能亮点

### 📸 微信式截图工具
- 🟩 绿色选区 + 外部压暗 + 实时尺寸标签，微信同款手感；
- 🖱️ 松手后**按住选框内部可移动**、框外可重新框选；
- 🔘 选框右下角三键工具条：【确认】【文字提取】【退出】；
- 🕐 时间戳命名 + 自动本地 OCR 生成同名 txt；
- 🎨 深色扁平 UI（面板/工具条/文字窗统一风格，可置顶、可最小化）。

### ⚡ 全局热键（0.2 秒直出截图）
- ⌨️ 默认 `Ctrl+Alt+S`，面板/托盘双模式；
- 🎯 **按下即捕捉**：在设置里直接按组合键即可自定义，无需手打；
- 🔄 热键交接零冲突：面板与托盘自动让位，双击桌面图标=覆盖式启动（自动杀旧开新）。

### 📋 DP 图片代码协议（招牌玩法）
```
截图确认 → 代码自动进剪贴板（如 DP-20260816-083600）
        → 聊天里 Ctrl+V 粘贴 + 提问
        → AI 收到代码即读取对应截图作答 ✅
```
- 🧾 代码 ↔ 文件严格一一对应，永不误读；
- 🎛️ 可配置：默认**单条模式**（粘贴永远一行），可切多代码模式（1~50 条自定义）或一键清空。

### 🔍 双引擎识图
- 🆓 本地 OCR 先探路：截图/文档免费秒读文字；
- 🧠 百炼 VL 再深看：A/B/C 三档（日常/旗舰/兜底），用户确认后才调用；
- 💰 每次调用如实报告 token 消耗（本次 + 累计）；
- 🚫 失败即停、不自动降级、不瞎猜内容——全流程"先问后做"。

### 🛡️ 隐私与占用治理
- 🔒 截图与 OCR **全程本地零联网**（仅 VL 调用时上传图片，调用前必提醒）；
- 🗂️ 截图自动轮换（保留最近 50 张）、诊断日志上限 200 行、代码队列可清空——**长期使用零堆积**；
- 🚫 无开机自启、无后台残留，右键托盘"退出"即彻底关闭。

### 📦 开箱即发布
- 📚 自包含手册（任何 AI 读一遍即接手全部规则）；
- 🧩 DSH / Claude 技能包（放入技能目录即自动触发）；
- 🪟 干净启动器（本机 csc 编译，规避杀软误报）。

## 🏗️ 工作原理

```
                     ┌─────────────────────────────┐
   图片 / 截图 ─────▶│  左瞳：本地 OCR（免费探路）  │
                     │  有文字？──是──▶ 先交付文字   │
                     │      │                      │
                     │      否                     │
                     │      ▼                      │
                     │  A/B/C 三档询问（用户拍板）  │
                     │      ▼                      │
                     │  右瞳：百炼 VL（付费识图）   │
                     │      ▼                      │
                     │  文字描述 + token 报告       │
                     └─────────────────────────────┘

   截图场景：截图工具 → 保存 PNG + OCR txt + DP 代码进剪贴板
             → 聊天 Ctrl+V → AI 按约定读图作答
```

## 🖥️ 平台支持

| 平台 | 支持程度 | 说明 |
|------|---------|------|
| **Windows 10 / 11** | ✅ 全功能 | 截图工具（面板/托盘/热键）、本地 OCR、百炼 VL、DP 协议全部可用 |
| Windows 7 / 8 | ⚠️ 部分 | 手册规则与百炼 VL 可用；截图可保存，但本地 OCR 通道不可用（缺系统 OCR 引擎） |
| Linux / macOS | ⚠️ 仅规则 | 手册为自包含规则，任何 AI 可读；截图工具为 PowerShell+WinForms 实现，不兼容，可按规则自行实现 |
| DSH（DeepSeek Harness） | ✅ 技能包 | `双瞳技能包` → `%USERPROFILE%\.dsh\skills\`（或项目 `.dsh\skills\`） |
| Claude Code / Claude | ✅ 技能包 | `.claude\skills\` 或 `~\.claude\skills\` |
| 其他聊天环境 | ✅ 手册方式 | 开场白一句话让 AI 读手册即可 |
| 模型自带视觉的会话 | ✅ 兼容 | "通道由用户选择"：自带视觉与双瞳并存，用户拍板 |

## 🚀 快速开始

> 完整图文步骤见 [📖 新手教程.md](新手教程.md)（约 10 分钟）。

1. 📂 整个文件夹拷贝到 Windows 10/11 电脑；
2. 🔑 获取百炼 API-KEY（**图文步骤见 [🔑 百炼API获取教程.md](百炼API获取教程.md)**）→ 打开 `模型.txt` 填写卡 → 单行替换保存；
3. 💬 新会话开场白：`请阅读 <路径>\双瞳识图方案手册.md，并按「首次使用：环境自检」执行。`；
4. 🖥️ 编译并双击 `工具\DuoPupil.exe`（或在聊天里让 AI 帮你启动）。

### 编译干净启动器（可选，推荐）

```
csc /nologo /target:winexe /out:"<路径>\工具\DuoPupil.exe" "<路径>\工具\launcher.cs"
```

> csc 位于 `%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`

### 安装为 DSH / Claude 技能

把 `双瞳技能包` 文件夹复制到技能根目录，**新开会话**生效。

## 🆘 常见问题

| 问题 | 原因与处理 |
|------|-----------|
| 🛡️ 火绒报 `HEUR:Trojan/LNKAgent.b` | 启发式误报。改用 exe 启动器 + 方案目录加火绒信任区 |
| ⌨️ 热键没反应 | 面板/托盘都没开；或组合键被占用（启动会弹警告）→ 换组合 |
| 🐢 热键延迟/时灵时不灵 | 旧实例在跑旧代码 → 双击「双瞳」覆盖式重启 |
| 👻 找不到托盘图标 | 点任务栏 `^` 展开；退出 = 右键图标 → 退出 |
| 📋 粘贴代码出现多行 | 默认单条模式；若需一次多图 → 快捷键设置 → 图片代码设置 → 多代码模式 |
| 💸 想查额度 | 百炼无公开额度 API；每次调用后 AI 会报 token 消耗，欠费/限流会明确报错 |
