# 双瞳 DuoPupil

给没有视觉能力的文本大模型装上"眼睛"：**本地免费 OCR 探路 + 阿里云百炼 Qwen 视觉模型识图**，并附赠一套微信式截图工具（DP 图片代码协议）。

## 特性

- **双引擎识图**：Windows 自带 OCR（免费、本地、零审批）先探路，百炼 VL 真正"看懂"（A/B/C 三档，用户拍板）
- **微信式截图**：框选/移动/全屏、绿色选区+外部压暗、深色 UI、时间戳命名、本地 OCR 同名 txt
- **DP 图片代码**：截图即得代码（剪贴板），聊天里 Ctrl+V 粘贴，AI 按约定自动对账，免手动报备
- **全局热键**：面板/托盘双模式，0.2 秒直出截图，支持按下即捕捉自定义组合
- **用户掌舵**：先问后做、失败即停、token 逐次报账、权限预告知
- 无开机自启、无后台残留、截图与 OCR 全程本地零联网（VL 调用除外）

## 快速开始（Windows 10/11）

1. 把整个文件夹拷贝到电脑；
2. 打开 `模型.txt` 填写卡，按卡内链接生成百炼 API-KEY 并替换为单行 Key；
3. 新会话开场白一句话：
   `请阅读 <路径>\双瞳识图方案手册.md，并按「首次使用：环境自检」执行。`
4. 桌面入口：双击 `工具\DuoPupil.exe`（若未编译，见下方）。

## 目录

```
├─ 双瞳识图方案手册.md      ← 完整手册（自包含，任何会话读它即可接手）
├─ 双瞳技能包/              ← DSH/Claude 技能入口（SKILL.md + references/）
├─ 工具/                    ← 截图工具全套（脚本 + 启动器源码 + 图标）
└─ 模型.txt                 ← API Key 填写卡（不含真实 Key）
```

## 安装为 DSH / Claude 技能

把 `双瞳技能包` 文件夹复制到：

- DSH：`%USERPROFILE%\.dsh\skills\`（或项目 `.dsh\skills\`）
- Claude Code：`.claude\skills\` 或 `~\.claude\skills\`

新开会话即可触发。其他环境无需安装，直接让 AI 读手册即可。

## 编译干净启动器（可选，推荐）

```
csc /nologo /target:winexe /out:"<路径>\工具\DuoPupil.exe" "<路径>\工具\launcher.cs"
```

csc 位于 `%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。

## 安全与杀软误报

工具由 PowerShell 脚本 + 本机编译的 4KB 启动器组成，**无联网、无加密、无传播行为**。已知火绒会把"快捷方式→powershell→隐藏窗口→脚本"启发式误报为 `HEUR:Trojan/LNKAgent.b`：请将方案目录加入杀软信任区（火绒：主界面 → 右上角菜单 → 信任区 → 添加文件夹）。详见手册「杀软误报说明」。
