# 双瞳 DuoPupil

给没有视觉能力的文本大模型装上"眼睛"：**本地免费 OCR 探路 + 阿里云百炼 Qwen 视觉模型识图**，并附赠一套微信式截图工具与 **DP 图片代码协议**。

> 双瞳 = 两只眼睛：一只是 Windows 自带 OCR（识字，免费本地），一只是百炼 VL（识图，付费按 token），互为补充、用户拍板。

## 平台支持

| 平台 | 支持程度 | 说明 |
|------|---------|------|
| **Windows 10 / 11** | ✅ 全功能 | 截图工具（面板/托盘/热键）、本地 OCR、百炼 VL、DP 图片代码全部可用 |
| Windows 7 / 8 | ⚠️ 部分 | 手册规则与百炼 VL 流程可用；截图工具可保存图片，但**本地 OCR 通道不可用**（缺系统 OCR 引擎），识图请直接用 VL |
| Linux / macOS | ⚠️ 仅规则 | 手册是自包含规则文档，任何 AI 可读可用；截图工具为 PowerShell + WinForms 实现，**不兼容**，可按手册规则自行实现本地 OCR 与调用脚本 |
| DSH（DeepSeek Harness） | ✅ 技能包 | `双瞳技能包` 放入 `%USERPROFILE%\.dsh\skills\`（或项目 `.dsh\skills\`），新会话自动触发 |
| Claude Code / Claude | ✅ 技能包 | 放入 `.claude\skills\` 或 `~\.claude\skills\` |
| 其他聊天环境 | ✅ 手册方式 | 无需安装：开场白一句话让 AI 读手册即可接手 |
| 模型自带视觉的会话 | ✅ 兼容 | 手册规定"通道由用户选择"：AI 自带视觉与双瞳通道并存，用户拍板 |

## 特性

- **双引擎识图**：Windows 自带 OCR（免费、本地、零审批）先探路 → 百炼 VL 真正"看懂"（A/B/C 三档：日常/旗舰/兜底，用户确认后才调用）
- **微信式截图**：框选/移动/全屏、绿色选区 + 外部压暗、深色 UI、时间戳命名、本地 OCR 同名 txt、截图自动轮换（保留最近 50 张）
- **DP 图片代码协议**：截图即得代码（自动进剪贴板），聊天里 Ctrl+V 粘贴，AI 收到代码即读取对应截图并作答——免手动报备
- **全局热键**：面板/托盘双模式，0.2 秒直出截图；按下即捕捉自定义组合；组合被占用自动弹窗提示
- **用户掌舵**：先问后做、失败即停、权限预告知、token 逐次报账、通道由用户选
- **隐私与占用**：截图/OCR 全程本地零联网；代码单条/多代码可配置、日志上限 200 行、截图上限 50 张；无自启、无残留

## 工作原理（一图流）

```
图片进来
  → 左瞳【本地 OCR】免费探路：有文字 → 先交付文字，问要不要 VL
                          无文字 → 直接 A/B/C 询问
  → 右瞳【百炼 VL】按用户选档调用 → 文字描述 + token 报告
截图场景：
  截图工具 → 保存 PNG + 本地 OCR txt + DP 代码进剪贴板
           → 用户 Ctrl+V 粘贴代码 → AI 按约定读图作答
```

## 快速开始

1. 整个文件夹拷贝到 Windows 10/11 电脑；
2. 打开 `模型.txt` 填写卡，按卡内链接生成百炼 API-KEY 并替换为单行 Key；
3. 新会话开场白一句话：`请阅读 <路径>\双瞳识图方案手册.md，并按「首次使用：环境自检」执行。`（AI 会自动完成 Key 校验、OCR 自检、模型列表拉取与 A/B/C 推荐）；
4. 截图入口：编译并双击 `工具\DuoPupil.exe`（见下方），或在聊天里让 AI 帮你启动。

**详细步骤见 [新手教程.md](新手教程.md)。**

## 编译干净启动器（Windows，可选但推荐）

```
csc /nologo /target:winexe /out:"<路径>\工具\DuoPupil.exe" "<路径>\工具\launcher.cs"
```

csc 位于 `%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。用 exe 作桌面入口可**避免杀软对"快捷方式→powershell→隐藏窗口"模式的误报**。

## 安装为 DSH / Claude 技能

把 `双瞳技能包` 文件夹复制到技能根目录（DSH：`%USERPROFILE%\.dsh\skills\`；Claude：`.claude\skills\`），新开会话即自动触发。当前会话的技能表是启动快照，装完**新开会话**生效。

## 常见问题

| 问题 | 原因与处理 |
|------|-----------|
| 火绒报 `HEUR:Trojan/LNKAgent.b` 并删除快捷方式 | 启发式误报（特征为"快捷方式→powershell→隐藏窗口→脚本"）。改用 exe 启动器 + 将方案目录加入火绒信任区 |
| 热键没反应 | 组合键被占用 → 启动会弹警告框，换组合（须含 Ctrl 或 Alt）；或面板/托盘未运行（热键只在二者其一生效） |
| 热键延迟 | 旧实例在跑旧代码 → 双击桌面「双瞳」= 覆盖式启动（自动杀旧开新） |
| 看不到托盘图标 | 点任务栏 `^` 展开折叠区；彻底关闭 = 右键托盘图标 → 退出 |
| 粘贴代码出现多行 | 图片代码默认单条模式；若为多行，去「快捷键设置 → 图片代码设置」切换单条模式 |

## 安全与隐私

- 工具由 PowerShell 脚本 + 本机编译的 4KB 启动器组成，**无联网、无加密、无传播行为**；
- 截图与 OCR 全程本地；仅当你选择调用百炼 VL 时，图片才会上传至阿里云服务器（调用前 AI 会提醒）；
- 本仓库不含任何密钥：`模型.txt` 只是填写卡模板，真实 Key 由用户本机保存（`.gitignore` 已拦截）。
